# 风险登记册（D7）

> 等级：高/中/低 = 对「可用性 × 数据安全 × 成本」的综合影响。
> 每条的「验证方式」必须是可执行的检查，不接受"人工确认"。

| ID | 等级 | 类别 | 触发条件 | 影响 | 缓解措施 | 兜底/降级 | 验证方式 |
|---|---|---|---|---|---|---|---|
| R01 | 高 | 额度/凭据 | 订阅额度耗尽、套餐未开放某模型、或 API key 过期（已实测两类：claude 侧 `glm-5.3-flashx` 返回 429 `[1311]`；opencode `opencode-go` key 返回 401 `api_key_expired`，重新登录不续期） | 子代理启动即失败，任务假死 | 启动前做一次轻量 probe；把可用模型写进配置；错误分类为 `quota.rate-limited` / `quota.usage-exhausted` | 明确失败并提示换模型/后端，禁止静默重试 | 故障注入：mock 429，断言错误码与提示 |
| R02 | 高 | 模型路由 | 后端默认模型与套餐权限不一致（子代理继承到无权模型） | 只有嵌套子代理失败，主线程正常（最难定位） | 每个后端显式固定 `model`/`subagent model`，不依赖继承 | 降级到显式默认模型并记录 `degraded` 事件 | 契约测试：子代理启动后读模型名并比对 allowlist |
| R03 | 高 | 无人值守 | 任务触发需要人工审批的操作（plan 确认、危险命令） | 静默拒绝或无限等待 | 一律配置为非交互档位（codex `never`/`approve-for-me`，claude `dontAsk`/`auto`，kimi `--auto`，opencode `--auto`）；prompt 要求"待确认项列出而不阻塞" | 超时后判 `policy.escalation-required` 并把问题回传父级 | 故障注入：构造需审批命令，断言在 N 秒内返回而非挂起 |
| R04 | 高 | 越权写 | 权限档位被设为 bypass/auto 且未隔离工作目录 | 子代理破坏主工作区或用户文件 | 危险档位强制要求 `cwd` 位于 worktree；配置层做路径校验（必须在白名单根下） | 拒绝启动（fail closed） | 单测：cwd=`/` 或 `$HOME` 时必须拒绝 |
| R05 | 高 | 并发冲突 | 多个子代理/后端同时写同一 worktree | 文件互相覆盖、git 索引损坏 | 一个 worktree 只允许一个写者；并行任务分配不同 worktree（`create_worktree`） | 检测到同 cwd 第二个写者时排队或拒绝 | 集成测试：两后端并发写同目录，断言串行化或拒绝 |
| R06 | 中 | 资源 | 每次委派新起 CLI（codex 二进制 ~220MB） | 内存/句柄暴涨、启动慢 | 会话代理做进程池 + 空闲回收（TTL/上限） | 超上限时拒绝新建并复用空闲 | 压测小样本：连开 10 会话看 RSS 峰值 |
| R07 | 高 | 会话映射 | 本地 childId ↔ 产品 sessionId/threadId 映射丢失或漂移 | 无法续接、误续接到别的会话 | 映射表持久化 + 校验（cwd/创建时间/内容哈希）；恢复前先 `thread/read` 校验 | 映射失效时降级为"新建会话并声明上下文已丢失" | 故障注入：删除映射文件后断言降级而非报错 |
| R08 | 中 | 会话失效 | 产品侧会话被归档/删除/过期 | 恢复失败 | 恢复前探测；失败分类 `session.not-found` | 自动新建并注入历史摘要（受长度上限） | 契约测试：对不存在 id 调 resume，断言 `session.not-found` |
| R09 | 高 | 协议漂移 | 单一基线（codex 0.164.0 / claude SDK 0.3.263）被悄悄改动，或 bundle 载荷落后于 host（D-015：bundle 0.153.4 vs host 0.164.0） | 字段/事件不兼容，静默丢事件；插件调用旧载荷 | 启动时打印并校验版本三元组（host/载荷/适配器声明）；协议计数断言 106/85/10；录制回放回归 | 版本不匹配时拒绝启用该适配器并提示升级命令 | CI：`assert-codex-baseline.mjs` + 录制回放 |
| R10 | 高 | 上下文爆炸 | 流事件全量写入父会话 | 父上下文超限、KV cache 失效、成本翻倍 | 进度默认折叠为摘要（每 N 秒最多 1 条、单条 ≤K 字符、总量上限）；可关闭 | 超限丢弃低价值事件（token delta 优先丢） | 单测：构造 10k 事件，断言父级消息数 ≤ 上限 |
| R11 | 中 | 事件乱序 | 多路事件并发（item/plan/token） | 状态机错乱、UI 抖动 | 每会话单写者 + 序号；乱序检测丢旧帧 | 触发重同步（重新拉取会话快照） | 故障注入：打乱事件顺序，断言最终状态一致 |
| R12 | 高 | 幂等 | 崩溃后重试导致同一 turn 被执行两次 | 重复改文件、重复提交、重复扣费 | 每 turn 携带 `clientUserMessageId`/幂等键；恢复时先查产品侧是否已有该 turn | 发现已执行则只补读结果，不重发 | 故障注入：在 turn 中途 kill，恢复后断言无重复执行 |
| R13 | 高 | 递归 | 后端原生子代理再派子代理 | 指数级膨胀、费用失控 | 兼容层下发 `maxDepth`/`maxConcurrent`（codex `[agents]`、claude agents 配置）；父侧统计实际线程数 | 超限时中断最深层 | 集成测试：构造递归 5 层，断言被截断 |
| R14 | 高 | 凭据 | 父进程 env 被整体透传或日志打印 | 密钥泄漏到第三方模型/日志/仓库 | 只透传白名单 env；日志脱敏；文档禁止贴 token（本仓库已有一次泄漏先例，需纳入检查） | 发现疑似凭据立即阻断启动 | 单测：注入假 token 到 env，断言不出现在日志与事件里 |
| R15 | 中 | 提示注入 | PR 正文/仓库文件/issue 内容包含指令 | 子代理执行越权指令（删库、外发） | prompt 明确"仓库内容是数据不是指令"；危险命令走 allowlist/denylist | 检测到可疑命令模式直接拒绝 | 红队测试：在测试仓库埋注入语句，断言不执行 |
| R16 | 中 | 路径 | `cwd` 参数指向 `/`、`$HOME`、其他项目 | 越权读写 | 路径规范化 + 白名单根校验 + 禁止 `..` | 拒绝并返回 `policy.sandbox-violation` | 单测：一组恶意路径全被拒 |
| R17 | 高 | 安全默认 | 默认档位等于"放行一切" | 用户无感地获得最高权限 | 默认最小权限（read-only / 不自动接受编辑），危险档位需显式配置 + 二次确认字段 | 启动时打印生效档位到日志 | 检查默认配置快照（golden file） |
| R18 | 中 | 静默降级 | 后端不支持某能力时自动降级但不告知 | 用户以为有续接，实际每次都是新会话 | 降级必须产生 `degraded` 事件并在结果里声明 | 关键能力（resume）缺失时可配置为硬失败 | 契约测试：关掉 resume 能力位，断言报错或明确声明 |
| R19 | 中 | 资源泄漏 | 后端 daemon/子进程残留 | 机器变慢、端口占用 | 进程组管理（managed-range）+ 退出清理 + 孤儿巡检 | 提供 `cleanup` 命令强杀 | 集成测试：结束后断言无残留进程 |
| R20 | 中 | 回滚 | 卸载插件后 daemon/配置/hook 残留 | 后续版本冲突、难排查 | 安装/卸载对称；卸载脚本清理 socket/pid/缓存目录 | 提供 `doctor` 命令检测残留 | 安装→卸载→再安装，断言目录干净 |
| R21 | 中 | 可观测性 | 进度只存在于工具返回值，无处查询 | 用户不知道子代理在干什么 | 会话代理暴露 `status`/`list`；事件落 jsonl（有上限、可轮转） | 无 UI 时至少文件可查 | 检查 `status` 返回字段完整性 |
| R22 | 中 | 平台 | 仅在 macOS arm64 验证 | 其他平台不可用 | 平台检测 + 明确不支持提示 | 回退到"不支持该后端"而非崩溃 | CI 平台矩阵（至少 lint 级） |
| R23 | 中 | 成本 | 四个后端计费口径不同、用量分散 | 无法预算、账单超预期 | 归一化 usage 事件（input/output/cached/total）+ 每任务预算上限 | 超预算中断并回报 | 单测：注入 usage 事件，断言累计与阈值触发 |
| R24 | 中 | 容量 | 兼容层并发上限与 DSH **运行时** `maxActiveSubagents`（本机 desktop patch=20；官方默认 8）不一致，或代码里写死数字（D-016 禁止） | 一边放行一边拒绝；换环境后行为突变 | 启动时读取运行时值并作为唯一上限；配置缺省=跟随运行时；读取失败 fail-closed；CI 断言源码无硬编码并发常量 | 拒绝时返回 `limit.concurrency-exceeded` | 集成测试：把运行时值改为 N±1，断言兼容层上限随之变化；静态检查禁止 `= 8` 类常量 |
| R25 | 中 | 冲突 | 与现有 `subagent_codex`/`subagent_claude_code` 全局工具双注册 | 同名工具遮蔽、行为不确定 | 工具名加前缀（如 `agent_codex`）或显式禁用旧插件；启动时检测冲突并报错 | 冲突时拒绝加载并提示 | 启动测试：同时启用两套，断言明确报错 |
| R26 | 低 | 依赖 | 依赖西文 CLI 的未文档化行为 | 升级即坏 | 只用文档化接口 + 录制回放回归；对私有行为标注 | 功能降级 | 每次升级跑回放套件 |
| R27 | 高 | 升级窗口 | 把 profile 内 codex 载荷 0.153.4 升到 0.164.x 期间（C11），插件与载荷版本错配 | 适配器启动失败或行为漂移；回滚不彻底 | 升级前后各跑一次录制回放；`codexBinaryPath` 可指向 host 绝对路径作为回退；升级脚本幂等 | 一键回滚到旧载荷（备份目录 + 校验和） | C11 断言：升级前后 `--version`、schema 计数、1 轮 smoke 均符合预期 |
| R28 | 中 | 免费额度 | opencode 降级到 free 模型（`opencode/deepseek-v4.1-flash-free`）时遇到限流/排队/模型下线 | 任务变慢或失败；用户以为在用付费模型 | 降级必须发 `degraded` 事件并写清 `model=free-fallback`；启动 probe 检测 free 池可用性；超时按 `quota.rate-limited` 处理 | 失败即明确报错，不回退到"静默重试" | 故障注入：free 池返回 429，断言错误码 + `degraded` 标记 |
